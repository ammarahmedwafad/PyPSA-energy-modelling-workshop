# Workshop materials for participants

This folder contains everything you need for the workshop.

## Open the notebook

| Notebook | Google Colab | Download |
|---|---|---|
| Workshop notebook (three short blanks to complete) | [Open in Colab](https://colab.research.google.com/github/ammarahmedwafad/pypsa-energy-modelling-workshop/blob/main/student/Python_Energy_Workshop_Student.ipynb) | [Python_Energy_Workshop_Student.ipynb](Python_Energy_Workshop_Student.ipynb) |

**JupyterLab (Anaconda).** Download this folder, open Anaconda Navigator, launch JupyterLab and open the notebook from the folder where you saved it. Keep the notebook and the `data/` folder together. If you are asked to choose a kernel, choose Python 3 (Python 3.11 or later).

**Google Colab.** Use the link above, or go to colab.research.google.com and choose File > Upload notebook.

In either case, run the first code cell. It installs PyPSA if it is missing and does not change any library already installed. The notebook explains each step and includes a guide to common errors.

## Documents

- Student workshop guide: steps, group roles, key terms and help.
- Student learning resources: curated links for Python, PyPSA, courses, open data and papers.
- Slides: the presentation used in the session.

## Data

- `data/pvgis_hourly_2019.json`: hourly PV output from PVGIS, so the notebook can run without downloading it again.
- `data/home.csv`: hourly solar generation and household demand used in Task 1.
